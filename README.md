# 🛡️ SpecInfo v20-core

**SpecInfo v20** is a modern, lightweight, and local-first hardware diagnostic engine. Designed for IT auditors, technicians, and hardware enthusiasts.

### 🚀 Key Features
* **Zero-Data Policy:** All diagnostics run locally in the browser. No data leaves your machine.
* **V20 Engine:** Unified module injection system and multi-language support (i18n).
* **Glass-UI:** High-performance hardware tests with a modern transparent interface.
* **Bi-lingual:** Full support for English and Polish.

### 🛠️ Tech Stack
- **HTML5** (Web Hardware APIs)
- **CSS3** (Custom Properties & Glass-morphism)
- **Vanilla JS** (Zero dependencies)
- **LocalStorage** (Audit persistence)
